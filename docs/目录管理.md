# 目录管理

正式代码放在 `src/invest/`；测试源码放在 `tests/unit/`。
配置放在 `configs/` 及根目录应用配置文件；环境安装和维护工具放在 `scripts/`。

当前架构、使用和运维说明放在 `docs/`；历史文档及随附证据统一放在
`docs/history/`。历史文档中的旧命令和路径仅作为历史记录，实际操作以当前运维说明为准。

正式数据库放在 `data/databases/`，状态放在 `data/state/`，采集证据放在
`data/evidence/`。新报告和审计成果放在 `reports/`，运行日志放在 `logs/`，
恢复依据放在 `backups/`。

测试数据、截图、探测结果和构建中间产物统一放在 `.tmp/`。
旧测试产物可在确认无运行进程引用后移至 `.tmp/history/`；不再向 `data/` 新增测试目录。
构建工具默认生成的 `build/` 属于可再生中间产物。
