# 测试目录

现有 16 个测试模块统一存放在 `unit/`，保留原有测试内容。
这批测试包含单元测试，以及使用临时数据库的集成和回归验证；
目录归档不改变测试性质，也不停止执行。

主要覆盖市场数据、股票与 ETF 策略、回测、日报、调度、数据库迁移和研究记录。
测试之间及结果一致性核验工具中的导入路径已同步调整。

在项目根目录运行全部测试：

```powershell
.venv-report/Scripts/python.exe -m pytest -q
```

`pytest.ini` 继续从 `tests/` 递归发现测试。
临时测试数据放入 `.tmp/tests/`，缓存放入 `.tmp/pytest_cache/`。
历史审计报告和旧测试产物不属于测试源码，本次不迁移。
