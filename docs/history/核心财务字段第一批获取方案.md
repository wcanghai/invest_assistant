# 核心财务字段第一批获取方案

## 1. 调整目标

通达信 `get_financial_data` 当前字段字典共有 438 个有效 FN 字段，接口按每批
100 个字段拆分时，每只股票需要 5 次调用。第一阶段改为只获取 92 个核心字段，
每只股票只调用 1 次接口，接口调用次数理论上减少约 80%。

第一批字段服务于价值、质量、成长、偿债、现金流、经营效率、盈利能力和财务
风险分析。业绩预告、业绩快报及大量行业专用明细暂不进入第一批，避免扩大采集
时间，也避免未来报告期字段被误用于历史回测。

数据仍写入 `stock_financial_report`：常用字段写入显式列，其余核心字段保存在
`raw_values_json`。核心更新采用 JSON 合并，不会删除数据库中已经获取的其他 FN
字段。

## 3. 获取与更新规则

1. 全量补齐从 `2004-01-01` 开始，按公告日筛选，调用
   `get_financial_data(..., report_type="announce_time")`。
2. `Financial` 阶段使用上述 92 个字段；`FinancialAll` 才使用全部 438 个字段。
3. 每日更新默认使用核心字段，并从每只股票财务域的上次成功截止日回取。
4. 主键保持 `(stock_code, report_date, announce_date)`，同一公告版本幂等更新。
5. 已有 438 字段记录与核心字段记录按字段合并，核心更新不清空旧字段。
6. 历史回测必须按 `announce_date <= factor_date` 取当时已公告的最新报告，不能按
   `report_date` 直接连接，以避免未来数据泄漏。

## 4. 后续批次
