# 全市场 ETF 轮动：实现与数据门槛

## 新策略与固定参数

`multi_rotation` 扫描所有经核验的股票、债券、黄金及商品 ETF；
`equity_rotation` 只选择其中的股票 ETF。二者不是个人投资配置建议。

月末使用 126/252 交易日收益均值和 MA200 过滤；最多五个槽位，每个基础权重20%。
同指数按历史60日成交额去重。正式版本同主题最多两只，126日相关性达到0.90时不新增；
共同有效观测少于100日同样不新增。前8名中的实际持仓可保留，只从前5名补充新持仓。
空槽位留现金。协方差固定10%对角收缩，研究波动目标10%，只减仓不加杠杆。

`configs/etf_full_market.json` 是独立的2.0配置。`verified_prices` 与严格历史时点认证分开：
前者要求价格和事件证据，可进行明确披露存续偏差的研究；后者仍要求完整历史身份及映射。

## 运行入口

完整冻结实验：

```text
python -m etf_strategy.full_market
```

运行窗口默认2016-09-12至2026-09-11；载入此前历史作为预热。A包括原五策略固定种子池，
B只扩展双动量池，C/D/E分别加入新Top5规则、暴露约束、保留区间；各有基础/10%版本。
F引用E的10%结果。另有沪深300买入持有参考，总计26种配置。

单独运行：

```text
python -m etf_strategy universe --config configs/etf_full_market.json --pool all_multi
python -m etf_strategy signal --config configs/etf_full_market.json --strategy multi_rotation
python -m etf_strategy backtest --config configs/etf_full_market.json --strategy equity_rotation --start 2016-09-12 --end 2026-09-11
python -m etf_strategy compare --config configs/etf_full_market.json --start 2016-09-12 --end 2026-09-11
```

最新信号可传 `--holdings` JSON，其内容为实际ETF代码到数量的映射；不传时按初始空仓计算，
诊断中记录持仓输入。人工交易清单优先使用传入账户的真实持仓，并沿用成交导入及对账。
成本和延迟压力测试重新计算实际持仓和后续信号，不缓存上一实验的持仓决策。

## 价格修复与发布拦截

原报告遗漏513100的1:5拆份，原收益和排名已撤回。新事件有share_change_date与resume_date，
保留ex_date用于兼容；不同日期的现金与份额事件须分别导入。
513100已导入官方公告证实的2022-01-12登记、01-13拆份、01-14恢复交易记录。

信号使用原始收盘价乘经核验的复权因子；账户使用原始价、实际份数及现金应收。
因子变化与事件后首个有效交易报价匹配，不要求它与停牌中的法律变更日期相同。
真实行情回归记录位于新报告目录的513100_actual_split_regression.json。

未解释的因子变化、绝对价格跳变达到40%、已持仓期间收益证据缺失均触发发布拦截。
40%是异常核验触发条件，不是自动判定拆份的算法；证实为真实大幅行情后应通过审计修正证据，
不得凭价格跳幅自行创造事件。现金股息缺失不能仅凭“价格未跳变”判定不存在。
完整性证书必须有独立来源；空接口响应不能自动生成证书。

## 数据补齐与追溯

分类新增exposure_type、theme_group、published_at和collected_at，旧导入可省略这些可空字段。
名称及主表跟踪标的只能生成核验候选，不能自动置verified=1。
历史公告发布时间与今天采集时间分别保存；历史有效区间不能因今天核验而直接扩展。

原始数据库采用增量迁移；研究结果和运行指纹在独立研究库中。
`verification_queue.csv` 扫描全量产品，按当期成交额排列补齐优先级，同时保留不合格原因；
这不是按今日流动性选历史组合。可继续使用collect、import-data及validate-prices补齐证据。
当前优先补齐历史分红、可靠价格调整口径和分类，禁止为了获得非空结果放宽门槛。

## 报告与验收

每配置有完整压缩筛选CSV、排名、决策说明、交易及独立中英文标识报告。
有可发布运行时额外输出日净值、实际权重、逐阶段收益、逐ETF损益贡献和收益/回撤/仓位图。
无合格活跃区间时不画现金零收益曲线、不参与排名，并列明资料缺口。
分红损益按权益产生时归属，支付只改变应收和现金，不重复产生收益。

共同区间使用最晚活跃信号日重新从现金运行。60/40历史分段保留边界日收益，明确非真正未见。
相同10%目标不代表实际风险相同，比较须查看实际波动率与回撤，不以提高年化作为代码验收。

自动测试覆盖真实拆份模式、分红账本、未解释跳变拦截、全量准入、实际持仓缓冲、行业约束、
相关性及样本不足、风险缩放、未来数据隔离、延迟成交与既有人工成交对账。
实现后的新数据应在固定配置下逐期积累前瞻记录，不把历史回测命名为前瞻实盘业绩。
