# 典型量化策略 MVP 方案

## 1. MVP目标

使用现有SQLite数据，以一个信号日为截面，生成几种典型策略的候选股票和等权目标组合。
MVP只做研究和模拟组合，不包含实盘下单、任务调度、复杂回测或参数优化。

共用的数据规则如下：

- 必须存在信号日的`stock_snapshot`；
- 仅使用信号日及以前的行情；
- 财务报告必须满足`announce_date <= 信号日`；
- 使用前复权价格计算收益；
- 剔除ST、退市整理、停牌、上市不足252日和低流动性股票；
- 各信号使用横截面百分位排名，分数越高越优；
- 目标组合默认20只股票、等权配置、单行业不超过20%的股票数量。

## 2. 四种策略

| 策略 | 核心信号 | 推荐调仓频率 | 主要风险 |
|---|---|---|---|
| `momentum` | 12-1、6-1、3-1月动量 | 月度 | 趋势反转、风格拥挤 |
| `low_vol` | 60日波动、下行波动、120日回撤 | 月度 | 牛市中可能落后 |
| `reversal` | 5日和20日反转 | 每周或双周 | 换手和冲击成本较高 |
| `quality_value` | PE、PB、股息、ROE、毛利率、负债和成长 | 月度或季度 | 价值陷阱、财务口径差异 |

## 3. 运行方式

运行全部策略并显示前20只股票：

```powershell
python -m factor_strategy.mvp --date 2026-09-04 --strategy all --top 20
```

只运行动量策略，并输出CSV：

```powershell
python -m factor_strategy.mvp `
  --date 2026-09-04 `
  --strategy momentum `
  --top 20 `
  --output-dir output
```

省略`--date`时使用数据库最新证券池快照。程序以只读模式访问数据库，不写策略结果表。

## 4. 最小验证标准

在用于模拟交易前，每个策略至少应完成：

1. 次日开盘成交的历史回测；
2. 佣金、印花税、滑点和涨跌停约束；
3. 与等权股票池基准比较年化收益、最大回撤和换手率；
4. 参数减半和加倍后的敏感性测试；
5. 明确标注当前历史证券池快照不足造成的幸存者偏差。

当前数据库只有四个历史证券池快照，因此本MVP适合生成当前候选组合，暂不应将长周期回测结果
解释为严格的无偏绩效。
