# ETF 三因子动量轮动策略

## 来源与分析

来源：[猫哥AI量化：ETF三因子动量轮动策略](https://mp.weixin.qq.com/s/GPqJrd4UiIKIgCV5DtfLJA)，
发布于 2025-12-07。本次通过 Chrome 浏览器和 Playwright DOM 读取正文。

原文将三种价格趋势指标做截面 Z-score，以 0.3、0.3、0.4 权重合成，
集中持有得分最高的一只 ETF，并以 1.5 倍门槛减少换仓。
三因子仍然都来自价格，不能视为三个独立风险来源；四类资产提供了市场分散，
但每次单只持仓依然有集中风险。Z-score 消除尺度差异，并不保证正态分布。
原文参数经过历史遍历，其收益存在参数选择偏差，不能直接推断未来表现。

## 规则与实现假设

| 项目 | 实现 | 与原文关系 |
|---|---|---|
| ETF 池 | 512890.SH、159949.SZ、513100.SH、518880.SH | 原文仅列四种类别，具体产品为本项目映射 |
| 乖离 | 收盘价/60日均线；最近25个乖离值除以首值后回归，斜率×10000 | 25日来自正文；60日为假设，要求完整窗口 |
| 斜率 | 最近25日收盘价除以首值，回归斜率×R²×10000 | 窗口25日为假设 |
| 效率 | OHLC平均价的24段对数收益×100×净距离/总距离 | 25个价格点为假设 |
| 标准化 | 每日四资产截面均值、总体标准差；零方差记0 | 标准化范围和ddof为实现约定 |
| 权重 | 0.3/0.3/0.4 | 原文公开参数 |
| 换仓 | 新最高分严格超过当前分+(1.5−1)×绝对值(当前分) | 修正负分语义；literal模式可直译倍数比较 |
| 信号/成交 | 收盘后计算，下一日期有效开盘成交 | 日频近似原文次日9:30执行 |
| 交易成本 | 单边佣金3bp、滑点5bp、100份整手 | 研究假设，不将1%的限价空间误当成交成本 |

默认不设绝对动量空仓过滤。全池数据有效后才排名，避免缺失资产改变截面。
行情空缺不填充信号；持仓暂缺价格时仅用上次收盘价估值，可能低估停牌期波动。
换仓任一侧无有效行情时延后，并在收盘按最新信息重新决策。
首次有效信号次日买入，末日仅给下一期目标，不虚构末日后的交易。

例如当前分−1、新分−0.8，直译阈值−1.5会立即换仓，而默认门槛−0.5不会换仓。
这项差异已提供单元测试。池中最优分通常为正，但接口仍明确处理负分。

## 项目数据与结果

只读 `data/security_pool.db` 的 `etf_daily`，不修改原始数据。
四只产品均有历史行情，最新日期为2026-09-08。
使用未复权交易价格，未计入分红、拆合份，未模拟涨跌停排队、盘口和成交容量；
尤其红利产品的分红会影响价格动量和收益。因此以下仅为价格口径研究结果。

默认配置，2019-01-02至2026-09-08：

| 指标 | 结果 |
|---|---:|
| 期末净值 | 6.1874 |
| 累计收益 | 518.74% |
| 年化收益（252日） | 27.86% |
| 最大回撤 | −40.32% |
| 夏普（无风险利率0） | 1.070 |
| 买卖记录数 | 139 |

这些结果不能认定复现原文“7年13倍”：产品、窗口、价格口径、样本终点和交易机制
均可能不同。未用该回测反向调整参数。上线前需补齐复权和分红数据，进行独立样本验证。

## 运行与产物

在项目根目录运行：

```powershell
python -m factor_strategy.etf_rotation
python -m unittest tests.test_etf_rotation
```

可用 `--db`、`--config`、`--output` 指定路径。
配置位于 `configs/etf_three_momentum.json`。
输出目录 `data/etf_three_momentum` 包含：

- `factors.csv`：各资产原始因子。
- `scores.csv`：每日综合评分。
- `equity.csv`：资金、份额、持仓和权益。
- `trades.csv`：交易日期、信号日期、方向、份额和含滑点成交价。
- `summary.json`：完整配置、绩效、最新评分及下一期研究目标。

此命令从历史重新计算，是研究回测与计划输出，不连接券商或自动下单。
输出文件会在相同目录重跑时更新；参数对比请指定不同输出目录。

验证包含常数回归、负分阈值、缺失信号、未来数据不影响历史、
下一日开盘成交、成本扣除与目标停牌，共5项单元测试。
