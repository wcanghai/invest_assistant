# 日报网站使用说明

## 已实现

本地轻量网站：`http://127.0.0.1:8766/`。沿用旧项目全部标的名单：2 只股票、6 只 ETF、
9 只指数、4 个具体期货合约、7 只美股和4个虚拟货币标的。

- 股票和 ETF 从本项目 `data/security_pool.db` 只读获取。
- 指数、期货、美股、虚拟货币用 Playwright 打开公开网页获取，每次行情存入本地。
- 提供历史日报及版本切换、网页更新按钮、Markdown 下载、行业概览、沪深北市场宽度、
  本地申购日历和缺失数据提示。
- 日报自然日与 A 股交易日分开。例如周六日报可显示周五 A 股和周六最新采集的外部行情。
- 相同输入生成同一版本；后续补齐数据生成新版本，保留此前版本。

## 启动与更新

在本项目目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start_daily_report.ps1
```

浏览器访问 `http://127.0.0.1:8766/`。点击右上角“更新网页行情”启动后台采集，页面显示完成状态。
浏览历史日报不会自动调用外部网页。服务只监听 `127.0.0.1`。

手工更新网页数据、读取本地行情并生成日报：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/refresh_daily_report.ps1
```

只使用本地已有数据生成日报：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/refresh_daily_report.ps1 -LocalOnly
```

常用 Python 命令：

```powershell
.venv-report/Scripts/python.exe -X utf8 -m daily_report.cli collect
.venv-report/Scripts/python.exe -X utf8 -m daily_report.cli generate
.venv-report/Scripts/python.exe -X utf8 -m daily_report.cli generate --date 2026-09-11
.venv-report/Scripts/python.exe -X utf8 -m daily_report.cli list
.venv-report/Scripts/python.exe -X utf8 -m daily_report.cli export --id 1
.venv-report/Scripts/python.exe -X utf8 -m daily_report.web --port 8766
```

`--date` 表示日报自然日。历史补报只使用在该日结束前已经采集归档的网页记录，
不会将今天抓到的价格写作过去的最新价。历史网页数据缺失会明确显示。

网页按钮更新今日日报，不更新当前正在浏览的历史版本。

## 网页来源及口径

| 类别 | 来源 | 日期和价格口径 |
|---|---|---|
| 8 只沪深指数 | 新浪指数桌面行情页 | 完整行情串中的价格、昨收及报价时间 |
| 中证2000 | 新浪移动行情页 `si932000` | 配置仍是 `932000.CSI`，实际来源有完整日期 |
| 国内期货 | 新浪期货页 / 倚天财经 | 最新价，相对昨结算涨跌；保留夜盘页面日期 |
| 美股 | 新浪美股页 | 常规时段价格及美东时间，与盘后价格分开 |
| 虚拟货币 | CoinMarketCap 资产页面 | 页面内嵌美元综合价、24 小时涨跌、UTC 更新时间 |

采集器解析浏览器页面实际加载的行情响应或页面自身内嵌 JSON，不要求 API 密钥，
不直接绕过网页调用外部行情 API。浏览器使用独立、无登录态的无头 Edge，不使用个人浏览器资料。
网页状态为 403 或404时记录失败，不绕过安全验证。网络超时等临时错误最多重试一次。
并发最多三个页面，CLI、网页和定时流程共享跨进程采集锁。

对照页面：

- [上证指数](https://finance.sina.com.cn/realstock/company/sh000001/nc.shtml)
- [中证2000](https://quotes.sina.cn/hs/company/quotes/view/si932000)
- [黄金 AU2610](https://finance.sina.com.cn/futures/quotes/AU2610.shtml)
- [苹果](https://stock.finance.sina.com.cn/usstock/quotes/AAPL.html)
- [Bitcoin](https://coinmarketcap.com/currencies/bitcoin/)

东方财富解析器保留为已验证的备用实现，但默认不使用：开发验证中部分桌面页改用持续流行情，
原 JSONP 请求不再稳定出现。Yahoo 在本机返回地区不可用页面；Coinbase/Coingecko 返回安全验证，
因此使用上表来源，不把这些失败页面当作行情。

## 自动运行接入

已在以下现有脚本的数据完成分支接入 `scripts/ensure_daily_report.ps1`：

- `scripts/run_daily_market_sync.ps1`：同步完成及“数据已完整”分支。
- `scripts/check_and_launch_daily_sync.ps1`：检查确认股票和 ETF 数据已完整的分支。

`ensure` 在该自然日尚无日报时执行网页采集并生成；已存在日报时只用归档网页数据和最新本地行情
重新计算，输入没变化不会新增版本。因此守护脚本每10分钟执行时不会反复抓取外部网站。
需要获取同一天更晚的海外行情，用网页更新按钮或 `refresh` 命令。
守护脚本以隐藏后台进程启动日报，避免网页超时占用守护任务本身的五分钟执行上限。
日报失败会给出单独警告，不改变已完成的股票/ETF采集结果。

本次没有新增或重注册 Windows 计划任务。现有任务若使用上述脚本，下次数据同步完成后会调用新流程。
周末现有 A 股守护任务会跳过，仍可在网站手动更新日报。网站服务需通过启动脚本运行，
未配置系统开机启动。

本次交付端口为8766；开发阶段8765的旧进程重启被自动审批拦截，暂保留。请使用8766查看新版。

## 文件和环境

| 文件 | 作用 |
|---|---|
| `configs/daily_report_universe.json` | 从旧项目完整复制的名单，保持原顺序和代码 |
| `daily_report/` | 采集、主库只读适配、报告生成、版本存储、HTTP 服务及静态页面 |
| `data/daily_report.db` | 网页采集记录、采集批次、不可变报告快照和 Markdown |
| `data/daily_report.collect.lock` | 操作系统级采集锁文件，遗留文件本身不表示有任务运行 |
| `reports/market_report_日期_v版本.md` | CLI 导出的 Markdown，网页下载直接读取数据库 |
| `.venv-report/` | 独立虚拟环境，不改变股票采集环境依赖 |
| `requirements-report.txt` | 生产依赖：Playwright |
| `requirements-report-dev.txt` | 开发验证依赖：Playwright、pytest |

在新机器上安装：

```powershell
python -m venv .venv-report
.venv-report/Scripts/python.exe -m pip install -r requirements-report.txt
```

需安装 Microsoft Edge。当前机器已具备 Edge，无需下载额外 Chromium。
运行网页采集需要网络；网站浏览已存日报和本地生成不需要外部网络。
删除虚拟环境后需重装依赖，不能只复制启动脚本。

## 数据限制

- 2026-09-11 本地有两只标记可交易的股票缺日线，另有涨跌字段缺失，报告显示“部分数据”。
  这类主库缺口不会通过假数据补齐；源数据修复后重新生成会反映新状态。
- 三年分位对股票使用项目现有复权因子，ETF使用未复权价格；样本不足或大段缺口显示空值。
- 外部市场从首次采集开始积累历史，没有导入三年网页历史，因此第一版不展示它们的三年分位。
- CoinMarketCap 是美元综合价，不是旧版 Kraken 交易对的成交价；旧标的代码仅作标的身份，页面明确注明来源。
- 期货严格保留 AU2610、AG2610、CU2609、SC2609，过期/停更时显示旧日期，不自动换月。
- ETF净值、折溢价和净申赎仍缺失；申购日历使用本地数据，未新增上市日、中签率、评级补采。
- 本地网站不包含账户、交易下单、AI摘要或策略自动执行。
