# 证券池开发与验证报告

## 1. 开发结果

已按前期简化方案实现以下文件：

- `security_pool/schema.sql`：8 张 SQLite 表及索引；
- `security_pool/db.py`：连接、建表、查询、批量写入和事务；
- `security_pool/fetcher.py`：通达信分类、股票、板块、IPO、可转债和 ETF 获取；
- `security_pool/processor.py`：字段转换、宽表构建、退出处理和校验；
- `security_pool/main.py`：数据库初始化、首次全量、每日更新和 IPO 更新入口；
- `tests/test_security_pool.py`：两日完整流程和失败回滚测试。

## 5. 特殊情况

- 可转债分类返回 328 只，数据库成功保存 328 只，无缺失；
- ETF 跟踪指数分类返回 442 个指数；
- 其中 439 个指数成功获得 ETF 数据；
- `A_NBI.OT`、`A_NDX.OT`、`Au99.99.OT` 为接口不支持的 `.OT` 指数；
- 获取代码已主动跳过 `.OT` 指数，避免后续产生无效接口错误；
- 最终保存 1,575 条 ETF—指数映射。

## 6. 运行方式

在普通 Python 环境中运行真实接口前设置：

```powershell
$env:PYTHONPATH='D:\software\tdx\PYPlugins\user'
$env:PYTHONIOENCODING='utf-8'
```

命令：

```text
python -m security_pool.main init-db
python -m security_pool.main full-load --date 2026-08-28
python -m security_pool.main daily-update --date YYYY-MM-DD
python -m security_pool.main update-ipo --date YYYY-MM-DD
```

交易日收盘后运行 `daily-update`；非交易日只需运行 `update-ipo`。
