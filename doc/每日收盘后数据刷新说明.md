# 每日收盘后数据刷新说明

## 现有每日增量能力

项目原有两个 Python 每日增量命令：

```powershell
python -m security_pool.main daily-update --date YYYY-MM-DD
python -m stock_data.main daily-update --date YYYY-MM-DD
```

前者刷新证券池当前宽表及每日快照；后者刷新股票行情、股本、除权除息、交易指标和财务数据。

新增的 `scripts/refresh_daily_stock_data.ps1` 将两者串联，并将股票拆分成小批次。每个批次
重新连接通达信，避免单次连接运行过久后失效。

## 手工执行

默认刷新中证500，日期默认为执行当天：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\refresh_daily_stock_data.ps1
```

指定日期：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\refresh_daily_stock_data.ps1 `
  -DataDate 2026-08-31
```

刷新全部活动 A 股：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\refresh_daily_stock_data.ps1 `
  -Scope AllA
```

财务数据由独立任务补齐时，可在每日任务中跳过财务，避免重复调用：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\refresh_daily_stock_data.ps1 `
  -Scope AllA `
  -Domains bar,capital,action,trade
```

脚本默认每25只股票启动一个独立的数据获取进程。重复执行会通过 SQLite UPSERT 更新已有记录，
不会产生相同主键的重复数据。

正式执行前必须启动并登录通达信客户端。非交易日会通过通达信交易日历检查自动跳过；只有在
明确需要时才使用 `-Force` 绕过该检查。

## 空跑检查

空跑不会访问通达信接口或写入数据库：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\refresh_daily_stock_data.ps1 `
  -Scope Csi500 `
  -DryRun
```

## 注册工作日定时任务

以下命令将任务注册到 Windows 任务计划程序，默认周一至周五18:00执行：

```powershell
powershell -ExecutionPolicy Bypass -File `
  .\scripts\register_daily_stock_refresh_task.ps1
```

先查看配置但不注册：

```powershell
powershell -ExecutionPolicy Bypass -File `
  .\scripts\register_daily_stock_refresh_task.ps1 -WhatIf
```

调整执行时间或范围：

```powershell
powershell -ExecutionPolicy Bypass -File `
  .\scripts\register_daily_stock_refresh_task.ps1 `
  -At 18:30 `
  -Scope AllA
```

定时任务使用当前登录用户的交互会话运行。执行时必须保持通达信客户端已登录，否则任务会失败
并在下次执行时重试。日志保存在 `logs/daily_stock_refresh_范围_时间戳.log`。

## 每日增量起点

每日任务不再使用固定的 14/30/400/20/730 天窗口。系统通过
`stock_data_sync_state` 按“股票 + 数据域”记录上次成功同步的截止日期，下次从该日期（含）
回取到目标日期并 UPSERT。包含上次截止日可以覆盖当天数据修订，同时避免每天重复扫描大段历史。

旧数据库第一次运行新策略时，会用各业务表已有的最后业务日期作为增量起点：

| 数据域 | 旧库初始化日期字段 |
|---|---|
| 日线行情 | `stock_daily_bar.trade_date` |
| 股本 | `stock_capital_daily.trade_date` |
| 除权除息 | `stock_corporate_action.event_date` |
| 交易指标 | `stock_trade_daily.trade_date` |
| 财务报告 | `stock_financial_report.announce_date` |

某只股票、某个数据域没有任何历史记录时，从上市日首次回补。即使接口返回空结果，只要请求
成功，也会推进同步状态，避免无数据区间在以后每天反复获取。
