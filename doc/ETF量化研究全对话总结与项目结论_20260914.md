## 三、资产池与原五种策略

### 3.1 共用筛选原则

历史信号日按以下顺序处理：历史身份与分类、上市和行情长度、数据质量、流动性、同暴露去重、策略候选。

| 条件 | 冻结规则 |
|---|---|
| 上市与历史 | 信号日已上市，至少253个有效收盘价观测 |
| 长期覆盖 | 最近253个交易所交易日有效行情覆盖率至少95% |
| 近期成交 | 最近20个交易日至少18日有效成交，信号日行情有效 |
| 流动性 | 最近20日平均成交额至少2,000万元 |
| 同指数去重 | 保留最近60日平均成交额最高的合格产品，并列按代码排序 |
| 规模与净值 | 发布时间不可靠时仅作诊断，不作为历史硬门槛 |
| 缺少候选 | 允许留现金，不降低标准补齐持仓数量 |

确认停牌可以按零成交额处理；未知缺失不能当作停牌。信号价格不向前填充，缺失收益不当作零收益。持仓估值允许沿用最近有效报价，但保留陈旧标记。

分类依据为基金文件和指数方法。黄金股票、商品股票属于股票暴露；信用债、可转债不作为默认避险资产；杠杆、反向和不明结构不进入基础范围。

### 3.2 五种原策略的定义

| 策略／代码标识 | 核心规则 | 主要作用和限制 |
|---|---|---|
| 多资产双动量 `dual_momentum` | 126/252日收益各占一半；动量为正且高于MA200；最多Top3；按60日波动率倒数分配；投资比例为入选数/3 | 比较趋势和相对强弱；可能偏重低波动债券 |
| 多资产趋势 `trend` | 股票、债券、黄金、商品各25%，类别内等权；逐ETF应用MA200，退出份额留现金；月度调仓 | 单独检验趋势过滤；震荡和快速反弹阶段可能失效 |
| 风险平价＋趋势 `risk_parity` | 126日收益至少100个共同观测，10%对角收缩；先类别内、再类别间等风险贡献；随后MA200过滤 | 避免某类产品多就占据更多风险预算；无杠杆时可能持有较多债券 |

原第一代基础种子为510300、513100、511010、518880、159985；因子候选为510030、515910、512260。前者只有五个代表产品，并非在全部1,723只ETF中完成择优。

## 四、旧十年回测为何撤回

### 4.1 旧结果仅作错误追溯

旧十年窗口为2016-09-12至2026-09-11。曾报告双动量7.51%、趋势5.11%、风险平价3.34%、战略配置6.89%的年化结果，第五策略未准入。

**上述四个数值及对应回撤、排名均已撤回，不是本项目当前有效绩效。** 此处保留数值，只用于识别旧产物和解释后续更正，不用于收益比较。

旧结果中现金较多、债券权重较高、小资产池和费用等因素曾被用于归因。拆份错误同时影响净值、信号与风险估计，因此这些占比和收益归因也需要重新计算，不能直接沿用为定量证据。

### 4.2 确认的错误与真实事件

513100官方公告说明：

- 权益登记日：2022-01-12。
- 份额拆分日：2022-01-13。
- 每1份拆成5份。
- 2022-01-14恢复交易。

旧行情中恢复交易日的原始收盘价比此前有效收盘价下降约80.45%。旧账本没有把份数乘以5，因而记入了虚假损失。原始价格还被用于动量、均线和波动率，导致后续持仓决策受到影响。

已导入官方事件并验证：份额变更日调整数量和陈旧估值，恢复交易后使用新价格。真实行情回归得到约−2.25%的当日持仓收益，拆份登记当天权益保持不变。

**结论：记账遗漏和信号口径错误必须共同修复，不能只调整最终收益。** 新的十年收益仍需在完整分红与复权依据核验后计算。

### 4.3 事件与发布机制的改进

- 区分份额变更日和恢复交易日，不再要求因子变化必须与停牌中的法律生效日一致。
- 因子变化与事件之后的首个有效报价匹配。
- 信号用经核验的调整价格；成交、持仓估值用原始价格及真实份数。
- 股息在权益产生时形成应收，到账时转现金，不重复产生收益。
- 未解释的因子变化、绝对价格跳变达到40%等情况进入核验；40%只是核验触发阈值，不能据此自动认定拆份。
- 异常涉及持仓，或持仓期收益证据失效时，阻止发布受影响组合绩效，不事后删除该产品美化回测。

最初测试虽然包含模拟拆份，但没有确保真实生产数据中的公司行动已经补齐。这说明：**账本单元测试通过，不等于真实回测的数据接入完整。** 后续增加了真实行情回归和发布拦截测试。

## 五、新版全市场轮动设计与实现

### 5.1 两条主线

- `multi_rotation`：股票、国债及政策性金融债、实物黄金、商品期货ETF共同竞争，不再预留四大类各25%。
- `equity_rotation`：仅限股票ETF，包括境内外宽基、行业、主题等。

二者共用动量信号：`M = 0.5 × R126 + 0.5 × R252`，要求动量为正且调整后价格高于MA200。按交易所交易日定位窗口；端点或均线窗口缺失时不产生有效信号。

### 5.2 持仓与轮换

1. 按动量降序、代码升序排序，最多五个不同指数暴露组。
2. 每个基础槽位20%，未填槽位留现金。
3. 同一标准化行业／主题最多两只，基础权重合计最多40%；不同市场的同主题也合并检查。
4. 候选与已选资产126日收益相关系数达到0.90时不新增；共同有效观测不足100个同样不新增。
5. 正式版本优先保留仍位于前8名、趋势和准入合格、符合组合约束的实际持仓，再从前5名补充新标的。
6. 月末收盘计算，最早下一交易日执行；无法成交保留实际持仓。保留逻辑不读取“上期计划持仓”冒充真实持仓。

### 5.3 风险控制

基础版使用槽位权重；目标版以126日收益、至少100个共同观测估计协方差，固定10%对角收缩，按以下比例缩减：

`缩放比例 = min(1, 10% / 估计组合年化波动率)`。

缩减部分转现金，不加杠杆。共同样本不足、协方差异常时取消当期新目标，保留原持仓并报告原因，不切换成其他策略。

相同10%目标不保证实际波动率一致，也不保证回撤上限。比较时必须同时查看实际波动率、回撤、现金及换手，不能仅凭目标相同就认定风险相同。

| `etf_master.underlying_code` | 1,694只非空 | 用于指数映射和同暴露去重候选，仍需核验含义 |
| `trade_unit` | 1,723只有正值 | 核验后接入整手数量规则 |
| `price_precision` | 1,723只非空 | 可辅助价格处理，不直接等同于完整历史最小报价规则 |
| `is_t0` | 1,723只非空 | 需确认含义和有效期，默认值也不能视为独立核验结果 |
| `etf_info` | 1,592条关联记录 | 指数关联、价格、IOPV、规模等字段的已有入口；不等同于1,592只独立产品 |
| `etf_snapshot` | 6,362条 | 已设计折溢价等字段，需要进一步检查有效值与发布时间 |

主表还有58只缺上市日期、29只缺跟踪标的。已核验身份表和交易规则表为空，不能推导出所有原始身份、交易字段也为空。

**修正后的结论：分类和交易元数据应先复用现有主表与映射，再补核验，而不是全部从零采集。** 股票宽基、行业、主题、纯风格、债券种类等经济含义，仍不能仅凭名称或一个非空标的代码自动确认。

### 6.4 可分阶段解决的其他缺口

- 退市、清盘产品及历史映射：影响生存者偏差；未补齐时可以进行明确披露的存续样本研究。
- 历史规模、净值发布时间：暂不用于严格历史信号，不必阻塞当前趋势和动量研究。
- 交易单位、价格步长、交易限制的有效期：人工数量订单阶段需要进一步核验。
- 个人账户资金、费率、真实持仓：数量订单和账户验证需要；权重研究不需要。

股票主表与ETF主表也没有代码交集。股票库因此不能直接补上ETF自身分红、份额变更和历史身份。ETF持有股票收到的股息，不等于ETF在同一天以同一金额向基金持有人分红。

可复用的部分包括：

- 日行情采集和`ForwardFactor`字段处理。

但股票事件表只有`event_date`、`cash_bonus`、`share_bonus`等字段；处理代码直接保存接口值，未在该处统一现金单位，也未分别保存登记、除息、到账日期。原采集范围来自股票主表，不能只改表名就认定ETF已覆盖。

后续可以扩展采集对象，并以ETF样本验证返回能力；空返回不能证明没有事件。股票股本、财务、行业数据不是当前ETF动量轮动的直接必需输入，除非另行开展成分股穿透研究。

## 十一、后续推进顺序

### 优先级一：建立最小可信收益样本

先处理510300、511010、513100、518880、159985已有行情与因子，补齐或确认研究区间分红、拆份及口径。对每个事件核对单位、关键日期和来源，形成真实核验记录。不能以无因子跳变或接口空返回代替完整性确认。

验收结果是：至少形成一组可发布收益的ETF样本和明确可用区间，而不是只增加因子行数。

### 优先级二：扩展可投资候选，而非重新制作全量主表

利用现有标的代码、ETF指数关联和交易元数据，批量生成待核验分类。优先处理历史较长、当期流动性较好的产品以安排工作，但历史组合仍按各历史调仓日重新筛选，不能使用今日流动性过滤历史。

核验后的新增产品自然进入候选池，不因其回测收益好坏决定是否准入。

### 优先级三：重新运行冻结对照并发布有效报告

先修正原基准，再比较单纯扩池、Top5、分散约束、保留区间及风险缩放。报告各策略有效区间和共同区间，披露实际波动率、回撤、现金、换手及成本压力。

只有这一步完成后，才能回答“扩池是否提高收益”“改善是否稳健”“收益提升是否主要来自增加风险”。

### 优先级四：完善历史可信度与执行验证

补历史退市产品、分类变更和交易规则有效期；需要数量订单时再加入账户资金、真实费率和成交约束。按冻结配置积累后续新增数据的观察记录，不将历史回测重命名为前瞻业绩。
