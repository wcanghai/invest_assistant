## 阅读说明

本文按“收益为什么可能存在 → 什么条件下适用 → 需要哪些数据和交易能力 → 怎样设计 → 最小示例 → 如何判断失效”展开。

需要区分三种内容：

- **研究证据**：来自论文、作者研究、监管机构或交易所，说明某种历史现象或交易机制。
- **设计建议**：本文结合个人投资者条件作出的判断，不等于已经证实有效的交易规则。
- **教学 Demo**：使用假设输入和人为指定参数解释逻辑。全部伪代码均不是可直接运行的交易程序，也未进行历史回测；示例盈亏不代表未来收益。

本文没有对这 18 类策略重新开展实证回测，也没有核验任何个人账户的权限。提及本项目已有文档时，仅说明可复用内容和文档记录的局限，不把此前结果当作新验证。

## 1. 策略分类与个人投资者的选择原则

### 1.1 不同名称可能描述不同层次

| 层次 | 回答的问题 | 例子 |
|---|---|---|
| 收益来源 | 为什么可能赚钱？ | 市场风险补偿、风格溢价、行为偏差、流动性补偿、价差收敛 |
| 信号 | 用什么观察或预测？ | 估值、盈利、价格趋势、盈利超预期、价差偏离 |
| 组合构建 | 买多少、如何分散？ | 等权、行业约束、风险平价、波动率目标 |
| 执行 | 怎样把目标变成持仓？ | 限价单、分批成交、TWAP、VWAP、订单管理 |
| 建模工具 | 怎样提取信号？ | 排名、回归、树模型、神经网络、文本分析 |

例如，“多因子＋机器学习＋指数增强”可能是同一个组合的三个描述；把这些标签列为互不相关的收益来源，会高估分散程度。CTA 通常是期货等市场的管理方式／策略集合，趋势跟踪是常见组成，也可以包含套利、基本面和其他信号。

定投是资金投入安排；TWAP、VWAP 是执行基准或算法。它们可以改善纪律或成交质量，但不能单凭名称推导出选股超额收益。

### 1.2 个人投资者的优势和短板

个人可以持有很久、控制交易次数、选择不参与，也不必维持机构规模。小资金降低了部分容量压力，但不能消除价差、最低佣金、交易单位和数据费用。

短板通常集中在：历史时点数据、融资借券、衍生品管理、执行速度、运行维护，以及发生异常时持续盯盘的能力。

据此，本文的优先级判断是：

1. **长期理财起点**：S01 ETF 配置与再平衡。
2. **个人研究起点**：S07 低频 ETF 动量、S08 不加杠杆的 ETF 趋势版本。
3. **数据能力较强时**：S03 价值质量、S04 低波、S06 低换手多因子。
4. **有专项经验后**：S10 配对、S12 事件、S13 可转债、S14 Carry、S15 期权。
5. **通常不适合作为业余起点**：S11 对冲组合、S16 结构套利、S17 高频做市；S18 机器学习应建立在可靠基准之上。

这是一种投入产出排序，不是未来年化收益排名。

## 2. 如何理解预期收益及策略性价比

### 2.1 四种收益不能混用

| 口径 | 含义 | 常见误区 |
|---|---|---|
| 绝对收益 | 账户自身赚了多少 | 牛市赚钱就认为策略有效 |
| 超额收益 | 相对事先确定的基准多赚多少 | 用低风险组合与高风险组合直接比较 |
| 风险调整后的收益 | 考虑波动、回撤或风险暴露后的表现 | 仅凭高夏普忽略尾部风险和估值平滑 |
| 个人经济收益 | 扣除交易、数据、工具与时间投入后的实际价值 | 忽略研究维护成本 |

长期做多股票因子的总收益包含市场涨跌。论文中“做多优质、做空劣质”的因子收益，不能直接当成只买优质股票的账户收益；同样，期货策略按保证金计算的收益，不能与按全部账户净资产计算的收益比较。

### 2.2 本文怎样给出预期收益判断

在没有限定市场、时段、杠杆、资金规模、费用和规则前，不给每类策略编造一个固定年化区间。预期收益按以下方式讨论：

- 配置策略：从基础资产的收益假设、比例和费用出发，主要目标是获得相应风险暴露。
- 因子、趋势：把历史证据视为待验证的收益来源；未来净超额可以为零或负数。
- Carry、卖期权：收入与承担的价格、融资或尾部损失一起评价。
- 套利、做市：从可成交价差减去全部成本及失败损失出发，计算账户净资产回报。
- 机器学习：必须证明相对简单模型有样本外的增量价值。

### 2.3 用情景估计代替单点承诺

假设某做多策略的可比基准收益为 5%，信号毛超额分别假设为 −2%、0%、+2%，增量交易和研究费用折合资产的 1%。三个情景下净收益近似为 2%、4%、6%。这些数字只是预算演示，不是行情判断或策略预测；基准本身也可能大幅亏损。

实际报告至少列：基准下跌、信号失效、成本上升，以及三个因素同时发生的情景。历史最差回撤不是未来损失上限。

### 2.4 成本能否吞掉优势

定义年度双边成交额倍数为“全年买入成交额＋卖出成交额”除以平均净资产。若该倍数为 20，每单位成交额的平均成本假设为 0.05%，简单估算的年度交易拖累约为 1%。成本随订单大小、流动性和市场状态变化，实际还应分买卖方向及税费计算。

最低佣金会改变小额订单经济性。假设一笔 1,000 元订单最低收费 5 元，单边仅佣金就是 0.5%；这不是实际券商报价，而是提示应使用自己的收费表。

假设 20 万元本金能多赚 3 个百分点，额外收益为 6,000 元；若耗时 200 小时，相当于每小时 30 元，尚需考虑超额收益的不确定性。学习本身的价值可以另算。

真实交易研究表明，成交成本及组合构建会改变可实现的因子收益；机构历史成交结果也不能直接替代个人账户费率。[交易成本研究](https://www.aqr.com/Insights/Research/Working-Paper/Trading-Costs-of-Asset-Pricing-Anomalies)

## 4. 通用设计流程与 Demo 约定

### 4.1 八步设计流程

| 步骤 | 需要做出的决定 | 最低交付物 |
|---|---|---|
| 1. 明确目标 | 收益增强、降低回撤、分散还是成交优化？ | 投资期限、风险预算和基准 |
| 2. 写经济假设 | 谁在付钱，为什么机会未消失，什么会使它失效？ | 一段可证伪的逻辑 |
| 3. 审核数据 | 当时知道什么、可以买什么、以什么价成交？ | 数据字典和时间轴 |
| 4. 定义信号 | 输入、窗口、方向、缺失和并列处理 | 可复算信号公式 |
| 5. 构建组合 | 仓位、行业、杠杆、流动性、现金、换手 | 目标权重和约束 |
| 6. 模拟执行 | 下单时间、成本、排队、失败、结算 | 订单与成交账本 |
| 7. 独立验证 | 时间切分、成本压力、参数邻域、市场变化 | 样本外与稳健性报告 |
| 8. 向前运行 | 版本冻结、监控、对账、暂停与恢复 | 模拟／小额运行记录 |

### 4.2 全部 Demo 共用的约定

1. 所有数字均为教学假设。伪代码中的函数代表需实现和验证的功能。
2. 日／月末信号在数据完整可用之后计算，成交采用下一可交易时点的实际价格；盘中策略使用独立时间戳和延迟模型。
3. 选股和排名使用当时可知的股票池、财报版本及公司状态；分红和公司行动正确处理。
4. 普通资产以净资产为仓位分母；衍生品同时记录名义敞口、保证金和全部账户权益。
5. 多头例子剩余资金进入现金；候选不足不强行补齐，不借钱凑满；做空只在实际有条件时模拟。
6. 信号价与成交价分开：复权／总收益序列用于研究收益，真实交易价格和实际份额用于记账。
7. 示例省略的手续费、税、滑点、结算和异常流程，不能在实盘系统中省略。

## 5. 逐类策略说明

### S01. ETF 资产配置与再平衡

**定义与收益来源**：事先确定股票、债券、黄金及现金的权重，定期或偏离阈值后恢复。收益主要来自持有资产；再平衡帮助控制风险，效果取决于资产路径，不保证超额收益。[SEC 资产配置说明](https://www.investor.gov/introduction-investing/getting-started/asset-allocation)

**使用场景**：长期资金、希望少交易、能容忍组合波动。短期必须使用的钱不应仅因策略简单而承受高风险资产波动。

**实现条件及难度**：行情和分红、基金费用、交易日历即可开始；原型 1、实盘 2。产品重叠、债券久期、黄金波动和跨境溢价是实际难点。

**预期收益与失效风险**：以所选资产组合为参照，不预设择时 Alpha。股债同时下跌、持续单边趋势、重新平衡成本都可能使结果不理想。

**方案设计流程**：个人期限和风险 → 选择不同风险来源 → 目标权重 → 偏离规则 → 费用和交易取整 → 与相同初始配置的买入持有比较。

**简化策略 Demo**：股票／国债／黄金／现金目标为 40%／40%／10%／10%，月末检查；任一类别偏离至少 5 个百分点则全部恢复目标。

~~~text
target = [0.40, 0.40, 0.10, 0.10]
if 月末 and max(abs(实际权重 - target)) >= 0.05:
    下一交易日生成恢复 target 的订单
else:
    保持持仓
~~~

假设组合 10 万元，实际为 46%／34%／10%／10%，忽略费用与取整时卖出股票 6,000 元、买入国债 6,000 元。最低验收：资金和份额守恒，分红入账正确，对照基准使用相同现金收益口径。

### S02. 风险平价与波动率目标

**定义与收益来源**：风险平价按资产对组合风险的贡献分配；波动率目标调整整体风险暴露。它们主要改变风险结构，不能自动创造预测能力。

**使用场景**：多资产组合、股票风险占比过大、希望限制波动变化。组合相关性结构变化和波动估计滞后时效果可能下降。

**实现条件及难度**：足够长行情、协方差估计、权重约束与换手控制；原型 2、实盘 3。使用杠杆后还需要融资、保证金和压力测试。

**预期收益与失效风险**：不加杠杆时常增加低波动资产比重，可能降低总收益；加杠杆虽能放大收益，也会放大融资与流动性风险。目标波动不是损失上限。相关研究提供历史机制和实证背景，并不验证本文参数。[风险平价论文](https://pages.stern.nyu.edu/~lpederse/papers/LeverageAversionRP.pdf)、[波动率管理研究](https://www.nber.org/papers/w22208)

**方案设计流程**：确定风险目标 → 估计波动与相关性 → 求约束权重 → 限制单资产和杠杆 → 设置调整缓冲 → 对比等权与固定配比。

**简化策略 Demo**：先做逆波动率权重，它只是风险平价的简化近似，不等于一般相关结构下的等风险贡献。

~~~text
raw_i = 1 / max(过去60日年化波动率_i, 波动率下限)
base_weight = raw / sum(raw)
应用单资产上限，并保留无法分配的现金
scale = min(1, 目标组合波动率 / 估计组合波动率)
final_weight = base_weight * scale
~~~

三资产波动为 20%、10%、20%，未加其他约束时权重为 25%、50%、25%。若估计组合波动 20%、目标 10%，整体持仓减至一半。完整风险平价需核查风险贡献：RC_i＝w_i×(Σw)_i／组合波动率。最低验收：协方差变化、接近零波动和危机相关性上升时，权重仍符合约束。

### S03. 价值、质量与红利

**定义与收益来源**：价值寻找相对盈利／资产／现金流便宜的股票；质量寻找盈利和财务更稳健的公司；红利考察股息率及持续性。可单用，也可结合，避免只买低估值困境公司或过度昂贵的好公司。

**使用场景**：中长期选股、低换手组合、能承受风格阶段性落后。金融和非金融企业的财务指标含义不同，应分组研究。

**实现条件及难度**：历史财务版本、披露日、当时市值、行业、分红与退市；原型 2、实盘 3。ROE 可能受高杠杆或低净资产影响，股息可能来自一次性分红。

**预期收益与失效风险**：历史价值、质量研究支持进一步检验，但不能把多空因子表现照搬为个人做多收益。便宜可能继续便宜，红利可能削减，质量可能被高价买入。[价值研究](https://www.aqr.com/Insights/Research/Journal-Article/Value-and-Momentum-Everywhere)、[质量研究](https://www.aqr.com/Insights/Research/Working-Paper/Quality-Minus-Junk)

**方案设计流程**：限定行业口径 → 清洗财务异常 → 行业内标准化 → 合成少量指标 → 季度调仓 → 分解价值、质量、行业对收益的贡献。

**简化策略 Demo**：同行业内使用 E/P、ROE、经营现金流／总资产的百分位排名；分别占 50%、25%、25%。

~~~text
eligible = 当时股票池中数据完整且符合盈利和质量条件的公司
score = 0.50 * rank(盈利收益率)
      + 0.25 * rank(ROE)
      + 0.25 * rank(经营现金流 / 总资产)
每季度按得分选择20只，目标等权，单行业最多25%
候选不足部分留现金；下一交易时点执行
~~~

假设 A 的三个排名为 80、60、40，得分 65；B 为 60、90、80，得分 72.5，B 排在前面。分红应进入总收益，不能把除息前股息率当作额外无风险收入。最低验收：抽查财报发布日和分红事件，指标与估值日期一致。

### S04. 低波动与低 Beta

**定义与收益来源**：低波关注价格自身波动，低 Beta 关注对市场波动的敏感度，两者不同。历史低风险异象与杠杆约束等机制有关，不意味着所有低波产品都能跑赢。[Betting Against Beta 研究](https://www.aqr.com/insights/research/journal-article/betting-against-beta?aqrPDF=1)

**使用场景**：偏防御的股票组合、希望降低股票部分波动。强劲牛市中可能明显落后，高股息公用事业等行业也可能形成集中。

**实现条件及难度**：总收益行情、停牌状态、行业和市值；原型 2、实盘 3。长期无成交的“零波动”不能当作低风险。

**预期收益与失效风险**：主要检验风险调整表现和回撤，而非默认更高绝对收益。历史低波不能防止跳空、财务风险或拥挤交易。

**方案设计流程**：过滤非交易和低流动性 → 估计波动／Beta → 行业约束 → 低换手持仓 → 比较同市场风险暴露的基准。

**简化策略 Demo**：

~~~text
每月对合格股票计算过去120日总收益波动率
保留有效观察足够、成交正常的股票
从低到高选30只，单行业不超过组合20%
等权持有，下一交易日执行
~~~

股票 A、B、C 的年化波动为 15%、25%、40%，其他条件相同则 A 优先；这只说明历史价格波动较低。最低验收：去掉不活跃交易导致的虚假低波，并报告行业暴露。

### S05. 小市值与规模策略

**定义与收益来源**：按公司规模构建偏小市值组合，研究规模相关收益。小市值不是低股价，流通市值与总市值也不能混用。

**使用场景**：能承受较大风格波动、具备个股分散和流动性管理的账户。只按最小市值排序的极端微盘策略，应与一般规模因子分开评价。

**实现条件及难度**：历史股本、市值、状态、退市和财务数据；原型 2、实盘 4。小资金有容量便利，但涨跌停无法退出、低流动性和退市损失仍存在。

**预期收益与失效风险**：规模溢价的稳定性和可实现性依赖市场、质量控制和成本；不能把所有微盘历史上涨都归因于可持续规模溢价。[规模与质量研究](https://www.aqr.com/Insights/Research/Working-Paper/Size-Matters-If-You-Control-Your-Junk)

**方案设计流程**：先剔除不可投和财务高风险 → 定义规模区间 → 检验流动性容量 → 行业分散 → 使用包含退市的样本 → 压力测试集中卖出。

**简化策略 Demo**：

~~~text
按当时总市值对合格股票排序
保留规模百分位10%至30%的公司，避开最小一端
过滤负净资产、亏损和低成交额
在行业约束下选30只，季度检查，等权持有
~~~

10%—30% 是示范参数，不是经验证最优区间。最低验收：报告低流动性时期可成交比例和退市损失，不能用当前存活股票反推历史收益。

### S06. 多因子与指数增强

**定义与收益来源**：组合多个信号；指数增强通常围绕特定指数适度偏离，争取超额收益，并控制跟踪误差。多个同源指标不一定提供独立信息。

**使用场景**：希望保留股票市场暴露、追求长期小幅增量、可以维护数据和约束。无约束前20名等权是集中选股原型，不应直接称为低跟踪误差指数增强。

**实现条件及难度**：时点因子、历史基准权重、行业和风险模型、成本；原型 3、实盘 4。难点是将预测转化为扣费后的组合价值。

**预期收益与失效风险**：市场收益加不确定的主动收益；因子失效、相互抵消、行业偏离和过度交易均可使增强为负。价值与动量历史互补不代表任意市场和窗口都负相关。[价值与动量研究](https://www.aqr.com/Insights/Research/Journal-Article/Value-and-Momentum-Everywhere)

**方案设计流程**：确定基准 → 选择有解释的少量因子 → 标准化和暴露控制 → 纳入成本 → 约束优化／保留规则 → 检验主动收益归因。

**简化策略 Demo**：使用 S03 的价值质量得分，或预先确定少量互补信号。

~~~text
每季度生成当时可知的综合得分
保留原持仓中仍合格且排名前40的股票
按分数补齐20只，单行业不超过25%，不足留现金
对比：无保留规则版本、合格股票池等权、宽基总收益
~~~

正式指数增强可进一步求解“预测主动收益 − 风险惩罚 − 交易成本”，并约束权重和为1、单股偏离、行业偏离和跟踪误差。最低验收：将市场、行业、风格和剩余收益分开；换手降低后的净收益必须实际测算。

### S07. 横截面动量与 ETF 轮动

**定义与收益来源**：在同一时点比较资产过去表现，持有相对强者。其假设是强弱排序可能持续，而非仅因为某资产曾经涨过。ETF 行业轮动与跨大类资产轮动的风险分散程度不同。

**使用场景**：价格趋势延续、资产相对强弱有持续性；希望减少财务数据依赖的个人研究。急剧风格反转、集中追涨和资产池过度同质时效果较差。

**实现条件及难度**：含分红行情、历史产品可得性、费用、上市和退市日期；原型 2、实盘 3。跨境 ETF 还涉及汇率、时区和溢折价。

**预期收益与失效风险**：历史动量研究支持检验，但个人做多版本同时受市场和集中暴露影响；极端反转、拥挤、换手会侵蚀收益。[动量研究](https://www.aqr.com/Insights/Research/Journal-Article/Value-and-Momentum-Everywhere)

**方案设计流程**：按资产风险来源建池 → 预先确定观察窗口 → 相对排名 → 可选绝对趋势过滤 → 限制集中与换仓 → 检验现金和风险暴露。

**简化策略 Demo**：与此前 30 天计划保持一致，使用 6 个月动量和 10 个月趋势过滤，最多两个各占50%的仓位。

~~~text
每月末计算各ETF的6个月总收益和10个月月末均线
合格 = 6个月收益 > 0 且 当前总收益价格 > 10个月均线
对合格ETF按6个月收益排序
第一名50%，第二名50%；空缺仓位留现金
下一交易日按实际可成交价格执行
~~~

假设股票、国债、黄金的6个月收益分别为8%、2%、12%，只有股票和黄金通过趋势过滤，则各持有50%。即使国债是所有资产中的相对第一，也可能仍为负收益；有无绝对过滤必须明确区分。最低验收：没有用今天最佳产品名单事后挑池；所有资产使用一致的分红、币种和时间口径。

### S08. 时间序列趋势跟踪与期货 CTA

**定义与收益来源**：根据资产自身过去价格变化确定多头、空头或空仓。均线、突破、过去收益符号是不同表达；CTA 并不等同于某一个均线公式。

**使用场景**：跨资产的持续趋势、希望加入与传统股票持有不同的收益路径。多空期货可以参与下跌趋势，普通做多 ETF 过滤策略通常只能减少敞口，不能直接赚下跌的钱。

**实现条件及难度**：ETF 原型2／实盘3；期货实盘4。期货需真实合约、乘数、保证金、换月、涨跌停和每日结算；连续合约图上的价格跳变不能直接作为可交易收益。

**预期收益与失效风险**：长历史研究提供跨市场证据，但单市场、少数 ETF 或不同仓位方式未必复制结果。收益可能集中于少数大趋势，震荡反复止损和突然反转是主要代价。[长期趋势研究](https://www.aqr.com/-/media/AQR/Documents/Insights/Journal-Article/AQR-JPM-Fall-2017.pdf)

**方案设计流程**：选择独立市场 → 定义方向信号 → 按波动或风险预算定仓 → 设置敞口与换月规则 → 测试趋势和震荡阶段 → 对比不择时配置。

**简化策略 Demo**：先做单资产、不做空、不加杠杆的月度过滤。

~~~text
每月末：
    若当前总收益价格 > 过去10个月月末均线：目标持仓100%
    否则：目标现金100%
下一交易日执行
~~~

价格110、均线105时持有；价格100、均线105时转现金。不是以均线105保证卖出，而是按信号后可获得的成交价。

期货扩展为“方向 × 风险预算 ÷ 单手价格波动金额”，再取整并限制名义敞口和保证金占用。最低验收：穿越阈值、跳空和连续无法平仓时的净值及风险均计入。

### S09. 短期反转、均值回归与网格

**定义与收益来源**：均值回归假设短期偏离会修复；股票反转常买近期跌幅较大的合格股票。网格是按价格层级分批买卖的执行和库存规则，是否赚钱仍依赖价格路径和持仓风险。

**使用场景**：偏离由暂时性流动性冲击而非基本面恶化引起、价格在区间反复波动且成本足够低。事后观察到震荡，并不能证明事前能识别震荡状态。

**实现条件及难度**：原型1—2，实盘4。需要真实可成交价、公司事件和流动性过滤；盘中网格必须满足标的回转交易条件和已有可卖库存限制。

**预期收益与失效风险**：可能有较多小额盈利，但持续单边下跌、跳空和越跌越买会积累大损失；上行中逐步卖空库存也可能落后持有。高胜率和频繁已实现盈利不代表净值改善。

**方案设计流程**：说明回归锚为何合理 → 过滤永久性信息冲击 → 设入场偏离和退出 → 明确最大库存、最大持有期和损失触发 → 将浮亏与成本一起计入。

**简化策略 Demo A：短期反转**

~~~text
每周在历史合格股票池中计算过去5个交易日总收益
排除重大负面事件、低流动性和不可买入股票
选跌幅较大的20只，等权持有至下一周检查
先估计完整换仓成本；有风险预算约束才生成订单
~~~

**简化策略 Demo B：有限库存网格**

~~~text
预先设定价格格点、每格数量、最大库存、资金上限和退出条件
价格下穿某格点：仅在资金与库存允许时买入一格
价格上穿某格点：仅卖出已持有且可卖的一格
每个格点订单维护唯一状态，防止同一次穿越重复成交
每次检查都按市价计算全部持仓盈亏
~~~

假设已有10股，成本100元；跌到90元再买10股。若价格到70元，持仓总成本1,900元、市值1,400元，浮亏500元；之前若有小额网格利润，也要一并计入账户总收益。教学“股”不代表实际交易单位。最低验收：单边下跌与跳空情景、库存上限、实际可卖数量、费用均正确。

### S10. 配对交易与统计套利

**定义与收益来源**：对具有经济联系的资产建立相对价格模型，价差偏离时一多一空，期待关系恢复。相关性高不等于价差平稳，也不保证能收敛。[配对交易原始研究](https://www.nber.org/papers/w7032)

**使用场景**：关系有经济依据、两个资产可同时买卖、价差模型在独立时段有稳定性。并购、业务改变、指数结构变化和借券中断可能永久改变关系。

**实现条件及难度**：原型3、实盘4。需要双边时间一致的行情、借券费用和供给、对冲比率、公司行动、持仓与保证金数据。不能借券时，仅买相对便宜一方不再是原来的多空策略。

**预期收益与失效风险**：利润来自相对收敛，通常需要覆盖双边费用和融资；历史价差突破可能是关系变化。统计套利不是无风险套利。

**方案设计流程**：经济筛选 → 只在形成期估计模型 → 独立交易期使用冻结参数 → 验证平稳性和半衰期 → 设最大持有期和双腿失败处理 → 滚动评估。

**简化策略 Demo**：

~~~text
形成期估计 log(A) = a + b * log(B) + residual
冻结 a、b、残差均值mu和标准差sd
交易期 z = (log(A) - a - b*log(B) - mu) / sd
z > 2：做空A、做多B；z < -2：做多A、做空B
按对冲比率和风险预算定名义仓位
abs(z) < 0.5、持有超20日或abs(z) > 4时提交退出
~~~

z＝2.5只表示按旧模型A相对贵，不说明差价必然回归。以对数回归系数近似确定名义对冲比率后，还要按实际价格换算数量；不应把系数直接当股数。止损触发不保证该价成交。最低验收：形成／交易期严格分开；报告借券、双腿未成交和关系断裂损失。

### S11. 股票市场中性与对冲 Alpha

**定义与收益来源**：做多预期较优组合，同时做空股票、指数或期货以减少市场方向风险。收益依靠多头相对对冲工具的优势，而非市场整体上涨。

**使用场景**：已有可信选股信号、希望降低 Beta，且有足够对冲与融资能力。金额中性不等于 Beta 中性，Beta 中性也不等于行业、风格和尾部中性。

**实现条件及难度**：原型3、实盘5。需要组合风险模型、历史与实时 Beta、实际借券或期货权限、基差、换月、保证金和压力测试。

**预期收益与失效风险**：Alpha 必须覆盖借券、融资、基差与换月成本；股票池和对冲指数不匹配可能产生较大残余风险。低净敞口可能同时存在高总敞口。

**方案设计流程**：先独立验证做多选股 → 选择匹配对冲工具 → 估计 Beta 和残余暴露 → 检验资本占用 → 模拟换月和保证金变化 → 对比未对冲组合。

**简化策略 Demo**：

~~~text
多头股票市值 L = 100万元
估计组合相对对冲指数 beta = 0.9
目标期货空头名义金额 H = L * beta = 90万元
手数 = 按当期合约价格和乘数换算并取整
检查账户权益、保证金缓冲、总敞口与残余Beta
~~~

假设股票涨6%、对冲指数涨4%，忽略基差、费用和取整，损益为6万元−3.6万元＝2.4万元；收益率须除以全部账户权益。总名义敞口为190万元，净名义敞口10万元，不能仅凭后者称风险低。基差是期货与现货价格差，其变化会改变对冲结果。[CME 基差与指数套利说明](https://www.cmegroup.com/education/trading-china-exposure)

最低验收：期货逐日结算、追加保证金和股票无法卖出的联合情景。

### S12. 事件驱动：财报、指数调整、并购等

**定义与收益来源**：围绕可识别事件研究信息反应、被动资金流或事件完成概率。常见包括财报后漂移、指数调整、回购、并购与要约收购。

**使用场景**：能获得精确公告时间和当时市场预期，事件逻辑重复且样本量足够。不同事件应分别建模，不把所有“利好公告”混为一种信号。

**实现条件及难度**：原型3、实盘4。需要公告原文和时间戳、公告前的预测数据版本、停复牌、交易限制以及事件重复去重。财报利润同比增长不等于超出市场预期。

**预期收益与失效风险**：历史研究观察到与投资者注意力有关的财报反应，但不保证当前市场仍能扣费获利；公告后跳空可能已经吸收大部分信息。[财报公告与注意力研究](https://www.nber.org/papers/w11683)

**方案设计流程**：限定一种事件 → 明确可用时刻和先验预期 → 做事件研究 → 设置可成交起点 → 设持有期与并发风险 → 与匹配行业和市场基准比较。

**简化策略 Demo A：财报超预期**

~~~text
surprise = 本次公布EPS - 公告前最后可得的一致预期EPS
按事先定义的历史预测误差尺度进行标准化
每个事件日仅选择正向超预期较强且数据完整的公司
公告完全可得后的下一可交易时点买入
最多持有20个交易日，事件组合单股权重受限
~~~

若实际EPS为1.20、事前预期1.00，原始差额为0.20；缺少事前预期数据时不能冒充这一策略，可单独研究“盈利加速”并更名。

**简化策略 Demo B：并购概率**：假设目标当前95元、完成支付100元、失败回落70元，主观成功概率90%，忽略时间与成本的期望期末价值为97元，预期毛收益约2.11%。盈亏平衡成功概率为(95−70)／(100−70)＝83.33%；概率估错和完成延期均会改变结论，不能将5元价差称作无风险收益。

最低验收：时间戳、预测版本、失败事件和长期停牌均纳入样本。

### S13. 可转债低价、双低与条款策略

**定义与收益来源**：利用可转债兼具债权与转股选择权的特点，研究价格、转股溢价、信用和条款。双低指价格与转股溢价率相对较低；与“买转债、动态做空正股”的可转债套利不同。

**使用场景**：理解债券条款、能持续检查公告和信用风险、愿意分散到多只债券。价格低于面值不能推导出保本。

**实现条件及难度**：原型2、实盘4。需当时转股价、正股价、剩余期限、债券现金流、赎回／回售／下修信息、发行人信用、成交和退出日期。

**预期收益与失效风险**：收益来自债券持有、股价上涨带来的转股价值变化及估值变化；违约、强赎、流动性丧失可能覆盖多年票息。普通双低仍有方向和信用风险。[证监局可转债风险说明](https://www.csrc.gov.cn/tianjin/c105377/c1263562/content.shtml)

**方案设计流程**：先读条款 → 信用与交易过滤 → 计算转换价值和溢价 → 分散选券 → 每日事件监控、低频换仓 → 重现强赎和退市的退出过程。

**简化策略 Demo**：

~~~text
每100元面值转股价值 = 正股价格 / 当时转股价 * 100
转股溢价率 = 债券价格 / 转股价值 - 1
在可投资券池内：score = 0.5*rank(低价格) + 0.5*rank(低溢价)
剔除不满足信用、流动性、强赎退出期限要求的券
按score选20只，限制单发行人暴露，每月检查组合
每天处理条款公告；事件退出优先于月度排名
~~~

假设正股10元、转股价12元、债券110元，转股价值83.33元，溢价率约32%。低价格和低溢价各自不构成完整估值。使用排名合成可避免不同单位直接相加，仍须验证经济含义。

交易规则会修订，实施时按适用交易所规则和募集说明书核验，不能沿用早年“无涨跌幅限制”的历史描述。[上交所可转债交易实施细则（2025年3月修订）](https://www.sse.com.cn/lawandrules/sselawsrules2025/bond/trading/currency/c/c_20250606_10781040.shtml)

最低验收：重现转股价调整、强赎和发行人违约事件；所有条款均按生效时点使用。

### S14. Carry：套息、期限结构与展期

**定义与收益来源**：Carry 描述在一定价格条件下持有头寸所产生的收入或成本，如利差、债券持有收益、期货期限结构效应。它不是统一的无风险利息策略。

**使用场景**：能理解融资、汇率、曲线和保证金，且具备对应资产和衍生品条件。不同资产 Carry 的定义、风险和可实现性不同。

**实现条件及难度**：原型3、实盘4。需要历史融资利率、远期点、到期曲线、实际合约、币种转换、现金担保和换月规则。

**预期收益与失效风险**：看似稳定的利差可能被价格变化或拥挤平仓覆盖；有利息收入不代表总收益为正。杠杆 Carry 的平仓可能放大价格变化。[BIS 对 Carry 风险的分析](https://www.bis.org/publications/carry-off-carry-on)

**方案设计流程**：定义具体 Carry 收入 → 明确价格和融资风险 → 比较已知收入与压力损失 → 分散 → 限制杠杆 → 真实合约记账。

**简化策略 Demo A：外汇套息算账**：以本币借入100，融资成本2%，按初始汇率换成100单位外币，以5%利率投资一年。若外币贬值8%，期末换回105×0.92＝96.6，本币需偿还102，亏损5.4。它是按初始名义金额计算的−5.4%，按投入保证金计算会是另一数值。全部为假设汇率和利率。

**简化策略 Demo B：商品期限结构信号**

~~~text
carry_score = log(近月期货价 / 远月期货价) / 两合约到期年差
每月在可交易商品中按carry_score排名
选择正向且流动性合格的市场，按风险预算配置
在真实合约上执行预定换月，记录换月价差及全部损益
~~~

近月100、远月98、期限相差一年，对应指标约2.02%；这只是曲线信号，不是已锁定年收益。外汇远期已反映利差，不能同时把现货利息和同一经济收益重复计算。最低验收：明确名义金额、账户权益、融资和换月现金流。

### S15. 期权与波动率策略

**定义与收益来源**：交易方向、波动定价、时间价值或尾部风险。常见有备兑、现金担保卖 Put、买跨式、卖跨式、价差、保护性 Put、Delta 对冲等；不同结构的收益分布差别很大。

**使用场景**：对标的、波动、到期和行权具有专项理解。备兑适用于愿意持有标的并接受上涨收益受限的情形；保护性期权用于付费限制部分风险。卖波动和买保护的目标不同。

**实现条件及难度**：原型3、实盘5。需要完整期权链、买卖报价、乘数、行权方式、分红、波动曲面、Greeks、保证金及流动性。到期损益公式容易写，动态风险管理较难。

**预期收益与失效风险**：卖方收到权利金但承担履约和尾部损失；买方损失可能是持续权利金消耗。隐含波动与历史实现波动的差异不是可直接锁定的利润，要比较相同期限、未来波动预测和对冲成本。

**方案设计流程**：先确定风险目标 → 选择有限风险或有充分担保的结构 → 画到期损益 → 压力测试到期前风险 → 模拟行权、对冲及手续费 → 小规模验证报价可实现性。

**简化策略 Demo：备兑**：持有1单位标的，成本100；卖出对应1单位、执行价105的看涨期权，收入2。忽略分红、费用和提前行权，到期利润为：

~~~text
profit = 到期标的价格 - 100 + 2 - max(到期标的价格 - 105, 0)
到期价80  -> profit = -18
到期价100 -> profit =   2
到期价110 -> profit =   7
~~~

上涨收益被限制，下跌风险只被2单位权利金部分缓冲；实际期权单位必须按合约乘数配足。备兑机制可参考交易所教育材料，其期货例子与现货账户仍有结算差别。[CME 备兑说明](https://www.cmegroup.com/education/courses/option-strategies/covered-calls)

最低验收：同时看总净值、最大损失情景、Delta／Gamma／Vega 和可成交报价。单一 Delta 中性不能消除 Gamma、Vega 和跳空风险；用中间价假设所有成交会高估收益。

### S16. 期现套利与 ETF 申购赎回套利

**定义与收益来源**：利用同一或高度对应资产的价格偏差，通过对冲与交割／申赎机制实现收敛。结构性收敛与 S10 的历史统计关系不同。

**使用场景**：具备同时交易两端、融资、交割或申赎条件，而且价差超过所有成本。只观察到 ETF 溢价并买入另一资产，不一定能锁定套利。

**实现条件及难度**：原型3、实盘5。需实时盘口、篮子组成、现金替代、申赎额度及时间、实际融资成本、分红、期货基差、最小单位和失败处理。

**预期收益与失效风险**：毛价差往往不大，真正重要的是净价差和资本周转。无法同时成交、申赎暂停、对冲标的不完全一致、融资变化都可能造成损失。[CME 指数套利机制](https://www.cmegroup.com/education/trading-china-exposure)、[上交所 ETF 申赎说明](https://www.sse.com.cn/assortment/fund/etf/question/)

**方案设计流程**：建立可执行的公允价值 → 用买卖两端报价算价差 → 扣完整成本 → 核验申赎／交割闭环 → 限制敞口 → 演练单腿失败。

**简化策略 Demo：净价差过滤**

~~~text
净价差 = ETF可卖出收入 - 篮子可买入成本
       - 申购相关费用 - 融资成本 - 税费 - 预估滑点
只有额度、最小单位、两端可执行条件满足，且净价差超过缓冲才提交计划
任何一腿失败都进入预先定义的撤单／对冲流程
~~~

假设按每份等值口径，篮子买入成本1.000、ETF可卖出价1.006、全部估计成本0.004，则理论净空间为0.002，即篮子成本的0.2%；不是每日都能实现的0.2%，也不能忽略实际申购单位或直接乘交易天数年化。

最低验收：完成一整套现金流闭环，按实际账户权益和占用时间算收益；跨境净值时间差、汇率和申赎受限单独处理。

### S17. 高频与做市

**定义与收益来源**：高频描述时间尺度；做市通过双边报价提供流动性，希望赚取价差，同时承担库存价格变化及逆向选择。不是所有高频策略都做市，也不是所有限价单都能得到价差收益。

**使用场景**：具有市场接入、费率、延迟、稳定系统和专业运维条件的交易者。普通个人面对相同公开盘口时通常缺少执行优势。

**实现条件及难度**：原型4、实盘5。需要逐笔订单和成交、排队位置、撤单确认、时钟同步、行情丢包与延迟建模，且核验交易权限、交易规则和报送要求。

**预期收益与失效风险**：极薄价差减去费用、库存损失和逆向选择；大量成交并不自动产生高收益。用日线甚至分钟线无法验证真实做市可行性。

**方案设计流程**：明确市场微观机制 → 估计成交强度和逆向选择 → 库存调整报价 → 模拟真实排队和延迟 → 异常保护 → 极小规模验证。

**简化策略 Demo**：这是库存倾斜思想的教学式，不是完整的 Avellaneda–Stoikov 模型。[原始做市论文](https://math.nyu.edu/inmemoriam/avellaneda/HighFrequencyTrading.pdf)

~~~text
报价中心 = 中间价 - 库存敏感系数 * 当前净库存
买价 = 报价中心 - 半价差
卖价 = 报价中心 + 半价差
库存到上限时停止新增买单；数据或连接异常时撤销可撤订单
按撮合规则、队列位置和确认延迟判断是否成交
~~~

中间价100、库存10、敏感系数0.01、半价差0.05，则中心99.90、买价99.85、卖价99.95。降低报价中心有助于减少库存，但如果报价跨越市场最佳价，可能成为主动成交并产生不同费用。

最低验收：价格触及不等于必然成交，撤单请求不等于已经撤单；记录成交后的价格漂移和断连时库存风险。

### S18. 机器学习、文本和另类数据方法

**定义与收益来源**：用模型从特征中提取预测，再结合组合和执行形成策略。树模型、神经网络、文本情绪等是方法，经济收益仍须来自可预测信息和交易优势。

**使用场景**：已建立简单线性／排名基准，拥有足够时点数据，怀疑变量间存在有经济意义的非线性交互。数据质量不足时增加模型复杂度往往放大问题。

**实现条件及难度**：原型3、实盘5。需要特征版本、标签完成时间、训练／验证隔离、模型版本、漂移监控和成本模型。文本还需发布时间、修订版本、授权来源；事后训练的大模型可能含历史事件结局，历史情绪回测要考虑这一污染。

**预期收益与失效风险**：研究发现机器学习在特定资产定价问题上具有预测增益，但不是任意数据和模型都获利。预测误差下降未必转化为更高净收益，尤其当改善集中在难交易的股票。[机器学习资产定价研究](https://www.nber.org/papers/w25398)

**方案设计流程**：先提出信号假设 → 设计可交易标签 → 构造当时可得特征 → 时间滚动训练 → 验证增量 → 转换成成本敏感的持仓 → 监测失效。

**简化策略 Demo**：

~~~text
特征X = 价值、质量、动量、低波、流动性等当时可得指标
标签y = 未来20个交易日总收益 - 同期基准总收益
每个训练截止日，只使用标签已完整结束的样本
按时间划分训练、验证、测试，处理跨边界重叠标签
用简单回归作为基准，再比较受限复杂度的树模型
按预测排名构建相同约束组合，扣除相同成本
~~~

20日标签意味着靠近截止日、尚未走完20日的样本不能进入训练；全样本标准化、随机拆分相邻日期、反复查看测试集都会泄露信息。最低验收：比较简单模型与复杂模型的净收益、换手、稳定性和维护成本，而不只看预测准确率。

## 6. 三套个人投资者起步方案

### 6.1 方案 A：先建立低成本配置基准

- 对应策略：S01。
- 最小资产池：宽基股票、国债、黄金和现金；基金品种按风险来源选，不按回测收益最高选。
- 初始研究规则：40%／40%／10%／10%，月末检查，任一偏离达到5个百分点则恢复。
- 必需数据：真实行情、分红和公司行动、基金主数据、交易日历、成本和交易单位。
- 第一份产物：信号表、目标权重、订单、持仓和净值，与相同初始配置买入持有比较。
- 核心判断：是否用可接受的风险和很少维护取得基础资产收益；不要求每年跑赢股票指数。
- 停止或调整研究的原因：资产定义不清、无法核对账目、组合损失明显超出个人承受范围。

### 6.2 方案 B：在同一资产池上研究低频趋势／动量

- 对应策略：S07＋S08。
- 规则：6个月相对动量、10个月均线过滤、最多两个各50%的仓位、其余现金、月末信号后执行。
- 第一份产物：每月全部资产的指标、排名、淘汰原因、实际仓位与现金记录。
- 基准：方案A、同池简单等权，以及相同风险暴露下的合理对照；所有对照统一现金收益与费用口径。
- 核心判断：多出来的择时和交易，是否在独立时段改善收益／回撤，而不是单纯提高股票或黄金集中度。
- 暂停扩展的原因：换一个相近窗口就反转、效果只来自一只事后选出的ETF、成本稍增就失效。

先做一个预先指定版本，再研究少量邻近参数。不能先在大量窗口和产品池中挑赢家，再把赢家当作独立验证对象。

### 6.3 方案 C：有可靠时点数据后做价值质量多因子

- 对应策略：S03＋S06。
- 股票池：每个历史时点的沪深300成分股；教学版本暂排除金融企业并进行盈利、数据和流动性过滤。
- 规则：50%价值＋25%ROE＋25%现金流质量，行业内排名；20只目标持仓，单行业不超过25%，季度检查，前40保留。
- 第一份产物：每只候选股票的原始指标、披露日期、行业排名、总分、入选或保留原因。
- 基准：宽基总收益、合格股票池等权；进一步与同行业配比基准比较。
- 核心判断：净主动收益是否超过数据和维护成本；行业／市值偏离是否解释了所谓因子收益。
- 数据不足时：只做当前截面和向前模拟，明确历史有效性待验证。

上述都是可讨论的初始规则，不是普适最优参数；资金规模可能使20只持仓不经济，应先核算交易单位和最低收费。

### 6.4 三套策略怎样组合

三套策略分别记账，再以组合层合并持仓与风险。不要因为策略名称不同，就认为已经分散。

教学例子：A占60%、B占25%、C占15%。若A股票目标40%、B股票最多50%、C全部做多股票，则按这些目标约束，合计股票敞口最高约为60%×40%＋25%×50%＋15%＝51.5%。这还不包含股票风格相关性、实际权重漂移及其他资产的风险。

组合检查至少包括：同一证券重复持有、行业与风格集中、现金是否重复分配、总敞口、压力行情相关性、合并后是否可以减少不必要的对向交易。上例是风险核算演示，不是实盘比例建议。

## 7. 回测、实盘和组合管理中的关键问题

### 7.1 最小数据模型

| 数据对象 | 关键字段 | 必须回答的问题 |
|---|---|---|
| 证券主数据 | 代码、上市／退市、生效区间、交易单位 | 当时是否存在、可否买卖？ |
| 行情 | 时间戳、OHLC、成交额、交易状态、来源 | 是实际可成交价格还是估值？ |
| 公司行动 | 分红、拆合股、除权日期和生效信息 | 现金和数量怎样变化？ |
| 财务 | 报告期、披露时间、修订时间、原始值 | 当时能知道哪个版本？ |
| 股票池／行业 | 成分及权重、生效起止、分类版本 | 是否用了今天的名单回测过去？ |
| 基金 | 跟踪指数、费率、净值、份额、申赎限制 | 是否重复扣费，是否混用净值与市场价格？ |
| 衍生品 | 合约、乘数、到期、结算、保证金 | 名义敞口与现金账能否对上？ |
| 信号与订单 | 数据截至时刻、生成时刻、目标、订单号 | 信号、下单、成交是否按时间发生？ |
| 版本记录 | 规则、参数、代码、数据快照 | 能否重现相同结果？ |

年度或季度累计现金流必须正确转换成需要的单季／TTM口径。简单累计净值不总等同于分红再投资总收益；ETF净值收益也不等同于二级市场按报价成交的收益。

### 7.2 统一回测时间线

~~~text
历史可得数据
    -> 形成可投资池与信号
    -> 风险约束后的目标组合
    -> 下一可交易时点的订单
    -> 实际成交／未成交／费用
    -> 现金、数量、分红与结算更新
    -> 组合净值和风险
~~~

收盘后得到信号，却按同一天收盘价成交，是常见时序问题。用开盘价近似下一日成交，也必须说明该近似不保证可获得，停牌、涨跌停和无足够流动性的交易不能直接成交。

### 7.3 独立验证如何安排

1. 先记录经济假设、候选市场、主参数、基准和成本，再看绩效。
2. 按时间设置开发、验证、最终保留区间；60%／20%／20%是教学切分，不是必须比例。
3. 保留足够指标预热；训练标准化、选股阈值及模型参数只使用允许的历史。
4. 最终保留区间只用于冻结版本的最终评估。看过结果后改规则，须记录测试区间已被使用。
5. 滚动验证时记录每次训练窗口、重估频率和成本；机器学习标签跨边界时执行清除或隔离。
6. 做少量参数邻域和成本压力检查，目的在于观察脆弱性，不是选择最高收益。
7. 将多个研究尝试纳入记录，防止只展示成功方案。

多次尝试后即便设置一次普通留出验证，也可能高估有效性；回测过拟合研究说明了这种选择偏差。[回测过拟合论文](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)

月频10年只有约120个月观察，跨股票的样本也可能共同受市场冲击，不能把大量相关记录当作独立证据。统计不确定性可用保留时间依赖的分块重采样等方式辅助估计，但区间仍依赖样本和方法，无法保证未来覆盖。

### 7.4 必须统一的绩效指标

| 指标 | 推荐口径 | 解读限制 |
|---|---|---|
| 累计／年化收益 | 无外部现金流时按净值复利；有出入金先区分时间加权和资金加权 | 短期高收益不宜简单外推 |
| 最大回撤 | 从历史净值高点到之后低点的最大跌幅 | 是已观察到的损失，不是风险上限 |
| 回撤恢复时间 | 回到此前高点的用时；未恢复则标注 | 同样回撤幅度可能对应完全不同体验 |
| 波动／夏普 | 明确频率、无风险利率与年化方式 | 自相关、非正态和停牌估值影响解释 |
| 主动收益／跟踪误差 | 使用事先指定且可比的总收益基准 | 基准不合适会夸大Alpha |
| 换手与成本 | 披露单／双边定义、总成交额、费用和净资产分母 | 最低收费和冲击非线性 |
| 敞口与杠杆 | 净、总、行业、风格、衍生品名义及保证金 | 净额很小仍可能承担大风险 |
| 流动性容量 | 订单额、成交额占比、未成交和退出时间 | 历史平均成交不代表危机可卖量 |
| 尾部损失 | 极端日／周、情景损失、条件尾部指标 | 样本没发生不代表不会发生 |
| 运维成本 | 数据费用、人工时间、故障频率 | 是个人性价比的一部分 |

不要以统一“夏普大于某数”作为所有策略上线门槛。低频配置与期权卖方的分布和目标不同，应按各自风险和证据评估。

### 7.5 按策略类型设计压力测试

| 情景 | 重点策略 | 应检查什么 |
|---|---|---|
| 股票和债券同时下跌 | S01、S02 | 分散是否失效、债券久期和权重是否过大 |
| 长期窄幅震荡 | S07、S08 | 反复换仓和费用拖累 |
| 持续单边下跌 | S09、S13、S15 | 库存、信用和期权尾部风险 |
| 急速反弹／风格翻转 | S03—S08 | 动量回撤、低波落后、趋势错过反弹 |
| 多只股票跌停或停牌 | S05、S06、S11 | 实际退出能力和对冲错配 |
| 相关关系断裂 | S10、S11 | 价差模型、残余敞口、止损可执行性 |
| 融资成本和保证金上升 | S11、S14—S16 | 现金缓冲与被迫平仓 |
| 重大事件失败 | S12、S13 | 跳空、停牌、条款退出期限 |
| 价差扩大和成交量下降 | 全部，尤其S09—S17 | 真实费用、容量和未成交 |
| 数据／连接故障 | 全部 | 新订单是否暂停、已有头寸如何管理 |

市场环境描述用于解释假设和压力测试。若策略需要先判断“现在是震荡还是趋势”，这个判断本身也是一个需独立验证的信号。

### 7.6 境内交易落地时应核验的条件

- 股票ETF与部分支持T+0的ETF交易制度不同，不能一律视为日内可回转。交易单位、涨跌幅和权限按具体产品核验。[上交所ETF规则问答](https://www.sse.com.cn/assortment/fund/etf/question/)
- 做空和对冲策略须使用实际可获得的借券／衍生品条件、费用和额度；普通买卖权限不代表这些能力已经具备。
- 股票、基金、债券、期货的税费和结算分别处理，使用届时适用规则和券商实际收费表，不统一套一个费用常数。
- 自动生成或执行交易指令时，应核对适用的程序化交易报送、接入和监控要求；不能把“个人账户”理解为天然不适用。[上交所程序化交易管理实施细则](https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20250612_10781696.shtml)
- 数据异常宜先暂停新订单并核对；强制减仓、恢复和异常退出应来自预先定义的规则，并考虑实际可成交条件。
